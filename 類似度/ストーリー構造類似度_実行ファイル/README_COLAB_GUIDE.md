# Google Colab 実行手順ガイド（無料枠 マルチアカウント分割実行版）

Google AI Studio の**完全無料枠（Free Tier）**を活用し、作品全6,267件の要約・ベクトル化を安全に完了させる実行手順書です。

---

## 1. 動作の仕組みとスケジュール

無料枠の1日あたりリクエスト上限（RPD）および1分あたり上限（RPM）を守りながら、2つのキーを交互に使うことで安全に処理を進めます。

- **複数キー自動ラウンドロビン**: 2つのAPIキーを指定すると交互に呼び出し、キーごとの待機間隔（4.1秒 = 15RPM未満）を厳密に保ちます。
- **1件ごとの即時ディスク同期**: 1件要約が成功するたびに `checkpoint_summaries.json` に即時フラッシュ保存（`os.fsync`）されるため、途中でColabの接続が切れても進捗は1件も無駄になりません。
- **1日上限（RPD）安全自動停止**: アカウントの上限に達した場合は、進捗を保存した上で自動で停止します。
- **過激描写作品の安全自動仕分け**: 各話あらすじに刺激的・過激な描写が含まれ Gemini API のセーフティフィルターで拒否された作品は、チェックポイントには書き込まず、別途 `blocked_works.csv` に自動記録されます。除外済みとして自動スキップされ、**ベクトル化・推薦プールの対象外**となります（最終ZIPには除外作品リストとして同梱されます）。
- **全件完了時の自動完走**: 最後の作品の要約・仕分けが完了すると、そのまま自動で **EmbeddingGemma 2 によるデュアルベクトル化**、**上位候補プールの抽出**、**成果物ZIPの作成** まで一気に完走します！

| 日程 | 処理内容 | 状態 |
| :--- | :--- | :--- |
| **1日目** | セル1〜6を実行 | 本日の上限に達すると自動停止・安全保存 |
| **2日目 (リセット後)** | セル1〜6を実行 | 自動で未処理分から再開し、自動停止・安全保存 |
| **3日目以降** | セル1〜7を実行 | **全件完了後、自動でベクトル化＆ZIP作成まで一気に完走！** |

> [!TIP]
> **完全全自動レジューム**: 毎日同じノートブックのセルを上から順に実行するだけで、スクリプトが未処理の作品を自動判別して進めます。進捗は Google Drive の `checkpoint_summaries.json` および `blocked_works.csv` に常時保存されます。

## 4. Google Colab での実行手順

1. **Google Colab を開く**:
   - [Google Colab](https://colab.research.google.com/) にアクセスし、`story_structure_similarity_colab.ipynb` をアップロードして開きます。
2. **GPU の確認**:
   - メニュー「ランタイム」→「ランタイムのタイプを変更」で **GPU (T4 または A100)** を選択します。
3. **セルを上から順に実行**:
   - **セル 1**: ライブラリのインストール
   - **セル 2**: Google Drive のマウント
   - **セル 3**: **API Key の入力**（1つ目と2つ目をプロンプトで入力。1キーのみの場合は2つ目を空欄でEnter）
   - **セル 4**: CSV ファイルのパス確認
   - **セル 5**: 出力先ディレクトリの設定
   - **セル 6**: パイプラインの実行
     - 自動で利用可能な最適なモデルを選択し、無料枠上限まで安全に進みます。
     - 上限に達すると自動で進捗を保存して安全停止します。
4. **翌日以降の実行**:
   - 無料枠がリセットされた後、再度Colabを開いてセル1〜6を実行してください。未処理分から自動で再開されます。
5. **最終日**:
   - 残りの要約が完了すると、自動的に **EmbeddingGemma 2 によるベクトル化** と **上位候補プールの抽出** が行われ、成果物ZIPが作成されます。
   - セル 7 を実行して **`story_structure_similarity_results.zip`** をダウンロードしてください。
