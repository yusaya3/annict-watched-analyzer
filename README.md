# Annict Watched Analyzer

アニメ視聴記録サービス [Annict](https://annict.com/) の「見た」記録を分析し、複数人での共通アニメ・ベン図・視聴シンクロ率・ジャンル傾向を可視化するモダンWebアプリケーションです。

---

## 🚀 主な機能

- **ベン図比較**: 2〜3人の重なり・共通視聴作品をインタラクティブなベン図で可視化。領域をクリックして該当作品（キービジュアル付き）を一覧表示。
- **シンクロ率マトリクス**: Jaccard係数に基づく趣味の近さをパーセンテージでスコア化＆ランキング。
- **トークのネタ・インサイト**:
  - 👑 全員が見ているアニメ
  - 💎 この人だけが見ているアニメ（独自推し枠）
  - 🚫 この人以外みんな見ているアニメ（未履修・逆張り枠）
- **作品逆引き検索**: 気になるアニメ名から「誰が見ているか」をインクリメンタル検索。
- **視聴アナリティクス ＆ ジャンル実験室**:
  - 🧪 **AniListジャンル実験室**: 15大ジャンルをAniListコミュニティタグ・代表作補正で高度分類（詳細は [新ジャンル分類解説](GENRE_CLASSIFICATION.md) を参照）。
  - 🔥 **視聴カロリー**: TV・映画・OVAの長さに基づき総鑑賞時間や日数を算出。
  - 📅 **年代別タイムライン**: 各年代ごとの視聴分布と「2人の共通黄金期」を算出。
  - 🎨 **制作スタジオ偏愛度**: 京アニ、動画工房、ufotableなど好む制作会社を集計。
- **📱 スマホ完全最適化**: 画面の横揺れゼロ、水平スワイプテーブル、チップセレクター対応。

---

## 💡 特徴と使い方（ブラウザ上で完結）

本アプリは **「1人単位の軽量差分取得」** と **「ブラウザ内リアルタイム集計」** を採用しており、誰でもストレスなく利用できます。

- **超高速（1〜2秒）**: 更新対象の差分データ（数十KB）のみを取得するため、Vercelのタイムアウト（60秒）や容量制限（4.5MB）とは無縁です。
- **各自で自由に利用可能**: 追加・更新したデータは各自のブラウザ（IndexedDB）に安全に保存されるため、他のユーザーの操作と競合しません。

### 基本操作
1. **ユーザー追加**: 右上の「ユーザー設定」から `@ユーザーID` を入力して追加（1〜2秒で即座に反映）。
2. **データ更新**: モーダル内の各ユーザーの横にある「更新」ボタン、またはヘッダーの「更新」を押すだけ。
3. **ユーザー削除**: モーダル内の「削除」ボタンで即座に除外。

## ☁️ デプロイ方法 (Vercel)

本リポジトリを [Vercel](https://vercel.com/) に連携してデプロイするだけで、即座に公開できます。

### 🔑 環境変数（任意・推奨）
トークンを設定しなくても自動的にWebスクレイピングで動作しますが、設定すると公式API経由でさらに高速・安定します。

- `ANNICT_TOKEN`: [Annict 設定 > アプリケーション](https://annict.com/settings/apps) で発行した「読み取り専用 (read)」トークン（Vercelの `Settings > Environment Variables` に登録）

## 🛠️ ローカルでの起動

```bash
npm install
npm start
```
ブラウザで `http://localhost:3000` を開きます。
