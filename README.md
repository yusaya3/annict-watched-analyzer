# Annict Watched Analyzer (2026 Modern Edition)

アニメ視聴記録サービス [Annict](https://annict.com/) の「見た」記録を分析し、複数人での共通アニメ・ベン図・視聴シンクロ率・ジャンル傾向を可視化するモダンWebアプリケーションです。

---

## 🚀 主な機能

- **ベン図比較**: 2〜3人の重なり・共通視聴作品をインタラクティブなベン図で可視化。領域をクリックすると該当作品（高解像度キービジュアル付き）を即座に一覧表示。
- **シンクロ率マトリクス (Jaccard係数)**: 趣味の近さを客観的にパーセンテージでスコア化＆ランキング。
- **トークのネタ・インサイト**:
  - 👑 **全員が見ているアニメ**
  - 💎 **この人だけが見ているアニメ**
  - 🚫 **この人以外みんな見ているアニメ**
- **作品逆引き検索**: 気になるアニメを入力して誰が見ているかを即座にチェック。
- **お試し実験室 (Labs)**:
  - 📊 **ジャンル別視聴傾向（AniListオープンDB照合）**: 18大ジャンル（Action, Comedy, 日常等）を自動付与し、各ユーザーの比率や作品一覧を比較。
  - 🔥 **視聴カロリー（総鑑賞時間・人生換算）**: TV・映画・OVAの長さに基づき総視聴時間や日数を算出。
  - 📅 **年代別タイムライン**: 各年代ごとの視聴分布。
  - 🎨 **制作スタジオ偏愛度**: 京アニ、動画工房、ufotableなど好むアニメ会社を集計。

## 🛠️ ローカルでの動かし方

```bash
# 依存パッケージのインストール
npm install

# データ取得＆ローカルWebサーバー起動
npm start
```

ブラウザで `http://localhost:3000` を開きます。

## ☁️ Vercel へのデプロイ方法

本リポジトリは Vercel に最適化されており、リポジトリを連携するだけで即座に公開できます。

1. 本リポジトリを GitHub にプッシュします。
2. [Vercel](https://vercel.com/) にログインし、「**Add New...**」➡「**Project**」を選択。
3. GitHub の本リポジトリを選択して「**Deploy**」ボタンを押します。
4. 数十秒で全世界に公開された URL（`https://your-project.vercel.app`）が発行されます。

---

## 📱 スマホ・Web公開版でのユーザー追加・更新方法

Vercel 上で公開後、比較するユーザーを追加・変更したい場合は、**GitHub Actions** を利用してスマホからワンタップで更新できます：

1. スマホのブラウザや GitHub アプリで本リポジトリを開きます。
2. 「**Actions**」タブを開きます。
3. 左側のワークフロー一覧から「**Update Annict Users & Analysis**」を選択します。
4. 「**Run workflow**」をタップし：
   - `action`: `add`（追加）または `remove`（削除）
   - `username`: 追加したい Annict のユーザーID
5. 「**Run workflow**」ボタンを押すと、裏で自動的にデータ収集と再集計が実行され、約1〜2分で Vercel のWebサイトが自動更新されます！
