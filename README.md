# Annict Watched Analyzer (2026 Modern Edition)

アニメ視聴記録サービス [Annict](https://annict.com/) の「見た」記録を分析し、複数人での共通アニメ・ベン図・視聴シンクロ率・ジャンル傾向を可視化するモダンWebアプリケーションです。

---

## 🚀 主な機能

- **ベン図比較**: 2〜3人の重なり・共通視聴作品をインタラクティブなベン図で可視化。領域をクリックすると該当作品（高解像度キービジュアル付き）を即座に一覧表示。
- **シンクロ率マトリクス (Jaccard係数)**: 趣味の近さを客観的にパーセンテージでスコア化＆ランキング。
- **トークのネタ・インサイト**:
  - 👑 **全員が見ているアニメ**
  - 💎 **この人だけが見ているアニメ（独自推し枠）**
  - 🚫 **この人以外みんな見ているアニメ（未履修・逆張り枠）**
- **作品逆引き検索**: 気になるアニメ名を入力して「誰が見ているか」を即座にインクリメンタル検索。
- **視聴アナリティクス ＆ ジャンル実験室 (Labs)**:
  - 🧪 **AniListジャンル実験室**: 18大ジャンル（Action, Drama, 恋愛等）をAniListコミュニティタグ・投票ランク・代表タイトル補正で高度分類。全員比較・独自ジャンル・差分分析に対応。
  - 🔥 **視聴カロリー（総鑑賞時間・人生換算）**: TV・映画・OVAの長さに基づき総視聴時間や日数を算出。
  - 📅 **年代別タイムライン**: 各年代ごとの視聴分布と「2人の共通黄金期」を算出。
  - 🎨 **制作スタジオ偏愛度**: 京アニ、動画工房、ufotableなど好むアニメ制作会社を集計。
- **📱 完全スマホ最適化**:
  - スマートフォン表示でも画面全体の横揺れがなく、マトリクステーブルの水平スワイプやユーザー切替チップを快適に操作可能。

## ⚡ 快適な分散更新アーキテクチャ（Local-First）

本アプリは、**「1人単位の超軽量差分取得（Incremental Fetch）」** と **「ブラウザ内リアルタイム集計（ClientAnalyzer）」** を組み合わせた分散アーキテクチャを採用しています。

- **超高速（1〜2秒）**: 1回のリクエストでは「更新したい1人の新着差分（数十KB）」のみを取得。
- **制限フリー**: Vercel無料枠の「60秒実行制限」や「4.5MBレスポンス容量制限」を100%回避。
- **完全な独立性**: 利用者がブラウザ上で追加・更新したデータは各自の端末（IndexedDB）に安全に保存されるため、他人の操作と競合せず、自分専用のダッシュボードとして自由に利用できます。

## 📱 ユーザーの追加・更新方法（Web画面上で完結）

特別な設定は不要で、Webサイトの画面上から誰でも直接操作できます。

1. **ユーザーの追加**:
   - 画面右上の「**ユーザー設定**」ボタンをクリック。
   - 「新しいAnnictユーザーIDを追加」に `@ユーザーID` を入力して「**追加して分析**」を押すだけ。
   - 1〜2秒でAnnictから視聴データが取得され、即座にベン図やシンクロ率に反映されます。
2. **個別ユーザーの最新データ更新**:
   - ユーザー設定モーダル内の各ユーザーの横にある「**更新**」ボタンを押すと、その人の最新差分データのみを取得して即座に画面全体を再計算します。
3. **全ユーザーの一括同期**:
   - ヘッダーの「**更新**」またはモーダルの「**全データを再同期**」を押すと、登録ユーザーを1人ずつ順次更新し、リアルタイムに画面が最新化されます。
4. **ユーザーの削除**:
   - モーダル内の「**削除**」ボタンを押すと、0.01秒で画面および設定から安全に除外されます。

## ☁️ Vercel へのデプロイ方法

本リポジトリは Vercel に最適化されており、リポジトリを連携するだけで即座にデプロイできます。

1. 本リポジトリを GitHub にプッシュします。
2. [Vercel](https://vercel.com/) にログインし、「**Add New...**」➡「**Project**」を選択。
3. GitHub の本リポジトリを選択して「**Deploy**」ボタンを押します。
4. 数十秒で全世界に公開された URL（`https://your-project.vercel.app`）が発行されます。

## 🔑 Annict 公式 GraphQL API 連携（任意・推奨）

本アプリは、Annict 公式 GraphQL API による高速データ取得に対応しています。
サーバー環境変数（Vercel または `.env`）にトークンを1つ設定しておくだけで、**サイトを利用する全ユーザーがトークン不要で公式APIの超高速・安定したデータ取得を利用できます**。
（※未設定の場合でも、自動的に通常のWebスクレイピングにフォールバックして動作します）

### トークンの発行と設定手順

1. [Annict 設定 > アプリケーション](https://annict.com/settings/apps) を開きます。
2. 「個人用アクセストークン」欄の「新規発行」をクリックします。
3. 説明（例: `Annict Analyzer`）を入力し、スコープは **「読み取り専用 (read)」のみにチェック** を入れて発行します。
4. 発行されたトークンをコピーします。
5. **Vercel の場合**:
   - Vercel のプロジェクト画面で「**Settings**」➡「**Environment Variables**」を開きます。
   - Key に `ANNICT_TOKEN`、Value にコピーしたトークンを貼り付けて「Save」します。
6. **ローカル環境の場合**:
   - リポジトリ直下に `.env` ファイルを作成し、`ANNICT_TOKEN=あなたのトークン` を記載します。

## 🤖 GitHub Actions による深夜自動同期（バックアップ）

リポジトリ内の [update-users.yml](.github/workflows/update-users.yml) により、**毎日深夜（UTC 19:00 / JST 午前 4:00）に登録ユーザーの最新視聴データが自動取得され、リポジトリへ自動コミット＆プッシュ**されます。

GitHub リポジトリの「**Settings**」➡「**Secrets and variables**」➡「**Actions**」に `ANNICT_TOKEN` を登録しておくと、Actions 内の定期更新も公式API経由で高速に動作します。
